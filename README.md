# Sales Forecasting & Business Analytics

## Project Overview

This project focuses on analyzing historical sales data to identify revenue trends, seasonal patterns, and high-performing product categories. The project also uses machine learning techniques to forecast future sales.

## Objectives

- Analyze historical sales data
- Identify sales and revenue trends
- Understand seasonal patterns
- Analyze product/category performance
- Build a sales forecasting model
- Evaluate model performance using MAE, RMSE, and MAPE

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook / Google Colab

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Preparation
5. Sales Trend Analysis
6. Data Visualization
7. Sales Forecasting
8. Model Evaluation

## Key Analysis

The project analyzes sales transactions to understand:

- Revenue trends over time
- Monthly and seasonal sales patterns
- Top-performing product categories
- Sales performance across different periods

## Model Evaluation

The forecasting models are evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Percentage Error (MAPE)
